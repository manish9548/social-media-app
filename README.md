# Social Media App 🚀

A full-stack social media web application built to share posts, connect with users, and manage profiles seamlessly.

## 🛠️ Tech Stack
* **Backend:** Node.js, Express.js
* **Frontend:** HTML5, CSS3, JavaScript
* **Database:** SQLite (`data/social.db`)

## 📁 Project Directory Structure
```text
social-media-app/
├── data/         # SQLite database storage
├── public/       # Client-side assets (HTML, CSS, JS)
├── server/       # Backend server logic, routes, and middleware
├── package.json  # Project dependencies and metadata
└── package-lock.json
